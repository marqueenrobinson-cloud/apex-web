Endpoints

Base URL: https://web-production-8a4a.up.railway.app

GET /brief?symbol=BTC $0.50

The paid route. Without payment it answers 402 Payment Required with the x402 payment details. Your agent pays and retries, then gets the brief.

GET /brief/any?symbol=BTC HOLDERS FREE

One route for everyone. A verified $APEX holder gets the brief free. Anyone else is sent to the $0.50 paid route.

GET /brief/holder?symbol=BTC FREE

Free for wallets holding at least 10,000 $APEX on Base. The wallet proves it's yours with a signed message (below).

GET /demo?symbol=BTC FREE

Try before you pay. Limited to a few calls a day per visitor.

GET /openapi.json

Machine-readable list of every route, for agents and tools that read OpenAPI.

How an agent pays

  1. Call /brief?symbol=NVDA.
  2. APEX answers 402 with the price, network (Base) and where to pay.
  3. Your agent signs a USDC payment with its wallet and sends the same request again with the payment attached.
  4. APEX checks the payment and returns the brief. It all happens in one round trip.

Any x402-compatible client handles steps 2–4 for you, including Coinbase's x402 libraries for Python and JavaScript.

curl -i "https://web-production-8a4a.up.railway.app/brief?symbol=NVDA"
# → HTTP 402 Payment Required + x402 payment details

What you get back

JSON with the symbol, how you got access, and the brief. Each brief has four parts plus a machine-readable call.

{
  "symbol": "BTC",
  "access": "paid",
  "brief": "SNAPSHOT … NUMBERS … RISK CHECK …
            BOTTOM LINE … CALL {…}"
}

CALL = {
  "asset": "BTC",
  "lens": "crypto",
  "direction": "down",
  "confidence": 0.60,
  "horizon_days": 7
}

Every call is scored later against what actually happened, so APEX's accuracy is tracked over time.
